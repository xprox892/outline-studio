# OUTLINE STUDIO — стартовый макет

## Файлы
- `index.html` — публичная страница и форма заявки
- `admin.html` — демонстрационная панель управления
- `styles.css`, `app.js`, `admin.js` — стили и логика

## Как открыть на Android
1. Скачай ZIP и распакуй его в папку на телефоне.
2. Установи редактор кода, например Acode или Spck Editor, из Google Play.
3. Открой папку проекта в редакторе.
4. Открой `index.html` через Preview / просмотр в браузере.
5. Для демонстрационной панели открой `admin.html`.

## Важно
Это фронтенд-прототип. Заявки хранятся только в localStorage конкретного браузера и не отправляются в Telegram или на сервер. `admin.html` пока не защищён паролем. Не публикуй эту демо-версию как рабочую систему для реальных клиентов.

Следующий этап перед запуском: подключить серверную базу данных, авторизацию администратора и серверную отправку уведомлений в Telegram. Токен Telegram-бота должен храниться только в секретах серверной функции, никогда в HTML/JS на сайте.
